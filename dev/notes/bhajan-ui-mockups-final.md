# GAnAmruta Thuli (GT) - Visual Mockups (Final Design)

## Project Name
**GAnAmruta Thuli** (గานామృత துளి)
- **Full Name:** GAnAmruta Thuli
- **Short Name:** GT
- **Meaning:** 
  - GAna (गान) = Song/Music (Sanskrit)
  - Amruta (अमृत) = Nectar/Immortal elixir (Sanskrit)
  - Thuli (துளி) = Drop (Tamil)
- **Philosophy:** Each song is a precious drop of divine nectar - small in the vast ocean of devotional music, yet infinitely sweet and nourishing
- **Significance:** Bilingual (Sanskrit + Tamil) representing that music transcends language

## Design Specifications

### Typography
- **Primary Font (Tamil):** Noto Sans Tamil
- **Secondary Font (English):** Inter / SF Pro
- **Display Sizes:**
  - Small: 18px
  - Medium (default): 22px
  - Large: 28px
  - XLarge: 36px

### Color Palette

**Calm Mode (Default):**
```
Background:     #F5F5DC (Warm Beige)
Surface:        #FFFFFF (White)
Text Primary:   #2C1810 (Dark Brown)
Text Secondary: #6B5D52 (Medium Brown)
Accent:         #FF9933 (Soft Saffron)
Border:         #E0D5C7 (Light Brown)
Highlight:      #FFF9C4 (Light Yellow - preserved from Docs)
```

**Dark Mode:**
```
Background:     #1A1A1A (Deep Charcoal)
Surface:        #2D2D2D (Dark Gray)
Text Primary:   #F5F5F0 (Warm White)
Text Secondary: #B8B5B0 (Medium Gray)
Accent:         #D4AF37 (Muted Gold)
Border:         #404040 (Medium Charcoal)
Highlight:      #3D3A2E (Dark Yellow)
```

### Spacing System
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- xxl: 48px

## Summary of Key Design Decisions

✅ **Text-only navigation** - Clean, no icons cluttering
✅ **Title-only song cards** - Simple, scannable
✅ **Collapsed special folders** - Reduced visual noise
✅ **Calm & Dark modes** - Reading optimized
✅ **Yellow highlight preservation** - From Google Docs
✅ **Smart offline** - Auto-download text, user choice for media
✅ **Metadata optional** - Works perfectly without
✅ **Customizable deity order** - Seasonal adaptation
✅ **3-column layout** - Optimized for 10" Android landscape
